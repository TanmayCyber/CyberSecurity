# GUI and CLI

<br>

## GUI

A Graphical User Interface (GUI) is an interface in which we interact with a computer using graphical elements such as windows, icons, menus, and buttons.

Insted of typing anything we click/drag elements using mouse to navigate. It is easier to learn navigateing in it and it is user-freindly.

## CLI

A Command Line Interface(CLI) is an interface in which we interact with a computer by typing commands in a terminal.

- It is faster, precise and uses lower resources than GUI while navigating.

Cybersecurity professionals spend a significant amount of time working in the terminal,
many security tools are designed primarily for the command line Example: Nmap, tcpdump, Netcat etc.

Even tools with graphical interfaces often provide additional features through the command line.

Learning the CLI is therefore an essential step toward becoming proficient in cybersecurity.

# Terminal and Shell

<br>

## Terminal

A Terminal is a program that provides a inerface for user to type commands in and interact with operating system.
Some popular terminals are: GNOME Terminal, Konsole, Xfce Terminal, Kitty and Alacritty. 

It only displays input and output.

## Shell

A Shell is a interpreter that interprets commands typed in terminal in computer readable form and interacts with operating system for output. Example: Bash, Zsh etc.

# Opening the Terminal

We can open the terminal by various methods:

1) Click Activities and search for Terminal.
2) Open it from the applications menu.
3) Use the terminal shortcut: `Ctrl + Alt + T`

---

# Closing the Terminal

You can close the Terminal by:

1) Clicking the close button
2) typing `exit` in terminal
